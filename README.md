# Daily Focus - To-Do List Web App

A simple, responsive task management application built with HTML, CSS and JavaScript. Tasks are saved in the browser using Local Storage, so they remain available after refreshing the page.

## Features
- Add new tasks
- Mark tasks as completed or active
- Delete individual tasks
- Filter all, active and completed tasks
- Clear all completed tasks
- Save tasks with browser Local Storage
- Responsive design for desktop and mobile
- Displays the current date

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## Run Locally
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a modern web browser.
4. Add a task to try the application.

## Project Structure
```text
todo-list-webapp/
├── index.html

```

## How It Works
JavaScript handles adding, completing, filtering and deleting tasks. The task list is stored as JSON in the browser's Local Storage, so it is saved on the same browser and device.
